# 天际线规模对照

日期：2026-09-11
阅读对象：用户

## 查到的上限（Cities: Skylines 1）

- 市民（Cims）：约 **1,048,576**（百万级，引擎数组上限）。
- 载具（所有在途类型合计）：原版 **16,384**。工坊 More Vehicles 提到 **65,536**。
- 路上同时跑的车远小于人口。你记的「百万人口、路上大约两万」和原版 16384 是同一量级。

百万人口不是一百万个路口。测试图按大约 18km 城、约 100m 街区，做成 **160×160 路口**（25600 个 Node）。

寻路次数先取 **20,000**，对齐原版载具上限一带；以后再加。

计算合同：`ComputeScheduler` 批量提交，CPU 多核算完再回传。GPU 走同一合同（排队、算完、回传），设备未绑定前 `GpuDeferredBackend.Available = false`。主线程只收结果，不在算的过程中插逻辑。
