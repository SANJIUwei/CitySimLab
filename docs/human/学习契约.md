# 学习契约

这个项目的目标不是一次性写出“正确答案”，而是训练你像游戏程序一样思考。

## 我们怎么学

- 每次只推进一个可以验证的小系统。
- 每个系统都要能用命令行或测试证明它在工作。
- 先接受简陋版本，再逐步替换成更真实的版本。
- 出错时先读现象，再猜原因，然后用最小实验验证。
- 设计文档会记录“为什么这样做”，不是只记录“做了什么”。

## 你要刻意练习的能力

- 把大游戏拆成小规则。
- 区分数据、规则、表现和输入。
- 用测试保护已有规则。
- 在改动前预测结果，在改动后检查预测。
- 能解释一个 Bug，而不只是把它修掉。

## 我会怎么教

从 2026-09-10 起：你策划和监督，AI 写实现。讨论清楚一小段后由 AI 改文件；你看结果、拍板或叫停。关键判断仍要讲清楚。详见 `docs/human/分工.md`。
