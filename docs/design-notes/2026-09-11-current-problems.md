# 当前逻辑层还没解决的问题

日期：2026-09-11
阅读对象：AI
状态：问题清单。已解决的标在标题里。

## 已经站住的部分

- 路网图层：Node / Segment / Lane；全局图不当建筑节点。
- 建筑缓存 `segment + t`。出行由 `TripStarter` 发起；未接入失败。
- `PathCenter` 收请求排队，作业交给 `ComputeScheduler`。点对点也进同一队列。
- 局部：同一段 t→t；跨段出门→入口 Node→全局→出口 Node→进门。
- `Thing.Advance` 能跳逻辑点。
- `Length` 和 `Cost` 已分开。

## 现在的问题

### 1. 事物还不会连续走

`Advance()` 一次跳一个路点。没有速度、没有每帧走一段距离。

### 2. 车道和图是两套拓扑

段上有 Forward / Reverse，邻接表 `_adj` 一律双向。单行以后会对不上。

### 3. 最近点接入扫全图，没有太远不接

`AttachNearest` 遍历全部路段，没有半径。城市一大就慢；离路很远也会挂上。

### 4. 路改了，建筑缓存不会失效

### 5. 还没有种类和世界节拍

没有车/人差别，没有每帧 `Tick` 的世界循环。Headless 只处理一次队列。

## 建议的下一刀

1. 接入加最大距离，太远就不挂。
2. 车道和图并成一份拓扑。
3. 事物按距离/节拍移动。

不要把建筑塞进全局图，也不要给每条车道再造 Node。
