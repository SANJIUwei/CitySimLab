# 你的第一个任务

不要一次做完整城市。

请选择一个非常小的起点，然后自己先试：

- 一个二维坐标。
- 一个地图格子。
- 一个时间 Tick。

建议你先选“二维坐标”，因为它足够小，又会在后面的地图、道路、寻路里反复出现。

## 要求

- 代码写在 `src/CitySim.Core`。
- 测试写在 `tests/CitySim.Tests`。
- 命令行观察写在 `src/CitySim.Headless`。
- 卡住时，把你看到的报错或输出发给我。

## 不要做

- 不要先查完整城市模拟架构。
- 不要先做 UI。
- 不要先做服务器。
- 不要一次写十个类。

先让一个小东西站住。
