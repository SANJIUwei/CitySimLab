# 道路系统验收清单

对应 [道路系统策划案](道路系统策划案.md)，不把未验证的工程条件算作通过。

| 策划项 | 可观察结果与测试 |
|---|---|
| 道路分类、断面和配置 | 现代中国大陆参考库有 13 个模板，覆盖城市四级、单双向支路、快速路主线与辅路、匝道、公路技术等级。公路路网归属另选；工程设计速度与标志限速分开。另有可选济南规则。见 `RoadTemplateCatalogTests` 和[选型依据](../ai/road-research/modern-china-road-templates.md)。 |
| 道路施工与真实连接 | B 进入铺路，T 选模板，可点空地、现有节点或现有道路的中间。单端接入或两端各接入不同道路时，施工前预览，最终重新校验并原子提交。立体跨越不自动连通；未接实体路口的同层相交、快速路平交、同层重叠会拒绝。设置过的车道、端点转向、相位与开口随分段保留。见 `RoadEditingTests`、`RoadConstructionTests`。 |
| 工程参数 | L 切换道路结构/层级，V 单独配置标志限速，N 为公路设置路网归属。已选规范有明确纵坡或最小净空时检查必要几何条件；显示的工程尺寸或参考设计速度不是工程审批。见 `RoadEngineeringGeometryTests`。 |
| 方向、车道用途、时段、转向 | 单行与车型/时段限制、按来向禁转、只入不出的终点、合法绕行、ALT 与 Dijkstra 代价一致；驶入时再检查实际时段。见 `RoadRulesTests` 和 `TimedRoadTravelerTests`。 |
| 开口与修改后的路线 | A 进入开口检查，点建筑，↑↓ 对照候选及排除原因；Enter 接入，Delete 关闭。按可连接与局部规则排序；高速主路、错层、距离或间距不符、障碍、分隔带等可以拒绝；右进右出不把公路变成单行。关闭开口或编辑道路后旧路线拒绝继续推进或重新规划。见 `RoadAccessAcceptanceTests`、`QueuedAccessChangesTests`。 |
| 信号与让行 | 区分圆红条件放行、红色右转箭头及红灯禁右转标志；圆红例外仅在明确配置且确认安全时允许，不在清空相位放行，不绕过永久禁转。无信号路口从真实冲突快照判断，不以等级猜路权。见 `SignalControlTests`、`UnsignalizedRightOfWayTests`。 |
| 多车、排队与货运 | 统一步进时钟，按车道保持跟车距离、前车和出口阻塞时等待、冲突转向不能同时占用路口。F 切换钢材厂→仓库，两辆货车出行；专门测试货车切换厂门后实际绕行，权重由 26 变 40，关闭出入口后不可达。经营、库存与贸易不在系统 15。见 `TrafficSimulationTests`、`RoadAccessAcceptanceTests`。 |

## 快速复测

在仓库根运行：

```sh
dotnet build -c Release
dotnet test -c Release --no-build
dotnet run -c Release --no-build --project src/CitySim.Headless
dotnet build src/CitySim.Godot
godot --headless --path src/CitySim.Godot -- --smoke
```

Godot 必须是 .NET 版。试铺路时先选点看预览，再点击终点落路；点在道路上会自动选择可验证的中间接入点，不点击确认不会修改路网。

## 验收边界

- 当前交付以现代中国大陆为参考数据组，不替用户拍板游戏的实际城市、年份、比例或地方风格。模板的净空与纵坡检查是工程几何的必要条件，不等于已模拟桥面结构厚度、曲线超高、详细断面或通过真实工程审批；未有可核对的数值不填。
- 编辑器是直线段式地图工作台。地形生成仍按用户要求搁置；无自动整城建路、最终美术或历史年代模板。选择现有线段中两点并直接相连会与原路重叠，不把这当作新道路。
- 多车实现机动车队列和冲突占用。未做行人流和完整换道/加减速模型；涉及行人、骑行者等冲突时需要调用者提供观测，未知不走圆红例外。未验证大规模交通性能。
