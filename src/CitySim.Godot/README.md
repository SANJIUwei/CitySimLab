# CitySimLab · Godot 预览

用 Godot 4.7.2 .NET 版打开本目录的 `project.godot`，需要 .NET 10 SDK。按 F6 运行 `CityView.tscn` 或按 F5 运行项目。标准版 Godot 不加载 C#。

演示地图包含 20 个路口、27 段道路和 6 栋建筑。预览按顺序回放 Core 的 ALT 搜索、显示金色路线，再由 Core 的时间游标让白点沿合法车道行进；到演示信号口遇红灯会停，绿灯后再出发。金色为本步确认，青色为已确认，蓝色为待确认或本步更新。地图数字是已走代价，右侧还显示地标估计得到的总代价。

路线确定后，面板对比 ALT 和 Dijkstra 在同一完整出行请求（包括两个道路接入点）中的搜索步数。左上角路段的箭头是真正参与搜索的单向车道。搜索状态包含来向车道，故一个路口可能出现多步。对照搜索仅用于演示，普通出行请求不会执行两遍。空格暂停或继续，右方向键单步寻路，R 重播，「交换起终点」对调两端。

- `CityDemo.cs`：示例数据和 Core 适配，不引用 Godot 类型。
- `CityView.cs`：负责渲染、搜索回放、UI 和驱动时间游标。单车游标有自己的演示时钟，不是整座城市的世界时钟。
- `CityView.Construction.cs`：B 进入铺路预览，T 切换模板。点击两个现有路口；绿色表示可建，红色显示不合法原因，蓝色交叉点表示只跨越、不互通。第二次点击合法终点才铺设，并按新路网重算出行。高架模板使用不同层的实际节点，不共享地面路口；现阶段是路段连线编辑，不是完整地形铺路和工程设计工具。
- Core 仍可独立运行；Godot 示例是可选项目，没有加进主解决方案。

单独构建与冒烟验证（在仓库根目录运行）：

```sh
dotnet build src/CitySim.Godot/CitySim.Godot.csproj
godot --headless --path src/CitySim.Godot -- --smoke
```

运行时命令的 `godot` 必须指向 .NET 版。
