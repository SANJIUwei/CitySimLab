# 建筑机动车出入口：先判断能否接入，再判断怎么走

核对：2026-11-20。范围是地块内部车行通道与城市道路之间的接口，不是楼门、人行出入口、地下车库坡道或快速路匝道本身。

## 现实资料

| 范围与来源 | 能确认的规则 | 不宜外推 |
|---|---|---|
| 全国：[GB 55011-2021《城市道路交通工程项目规范》住建部公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2021/art_17339_761190.html)，2022-01-01 实施；[规范正文第 3.2.2 条](https://www.zlglpt.com/book/book_view.aspx?id=3793) | 道路平面要结合交通组织，协调交叉口、出入口、分隔带与缘石开口等。 | 这是统筹要求，不能从这一条推出全国统一的建筑开口退距，或各等级必然使用同一种开口。 |
| 济南：[《济南市国土空间规划管理技术规定》第 2、114、165–166 条](https://nrp.jinan.gov.cn/col/col43831/art/2026/art_e6f74eabc17e4c668a033e5197675478.html)，2026-04-15 实施 | 地块不接快速路主路。大量人车出入的地块，宜先走周边路网，不宜直接接快速路辅路。车站、学校、医院等公共设施确需接快速路辅路或主干路时，按右进右出组织。临多条路，机动车入口宜优先放在等级较低者，并满足交叉口间距要求。 | 这是济南市辖区的规划规定，各县可参照或自定；辅路并非天然可开口，也不是所有地块、所有双向道路都须右进右出。 |
| 深圳：[市交通运输部门针对具体开口咨询的答复](https://www.sz.gov.cn/hdjlpt/detail?pid=2905405) | 该答复说明，特殊情况下需要开口时，应设在辅路，并针对快速路辅路与主干路辅路分别说明间距要求。 | 这是地方办事答复，用于对比条件和口径，不把数字写成全国或游戏默认。 |
| 金寨：[政府公开答复所述的主干路小区案例](https://www.ahjinzhai.gov.cn/content/article/38810014) | 车辆出小区时右转并入同向车流，不能直接横过对向车道左转或掉头。 | 用作右进右出的具体例子，不以答复替代规范正文及其适用场景。 |

右进右出限制的是**开口允许的转向**：靠开口一侧的同向车流可右转进，出门右转汇入同侧方向；对向来车不能在开口处横穿左转。如果要从对向进来，需要到允许转向或调头的地点绕回来。道路本身可以依然是双向的。

## CitySimLab 候选方案，未决定

[用户已定的设计原则](project-decisions.md)：道路规则按现实设计，不设原型专用的临时规则。以下只是数据表达建议。

现有 `Building.AttachNearest` 按门与路段的距离选最近路段，不区分它是否允许地块接入，也没有开口的进出方向。保留 `segment + t` 作为位置，另拆出两个问题：

1. **有没有可用的开口**：示例是离楼最近的是快速路主路，但主路不可接；改找同层、连得上的支路或允许开口的辅路。如果都没有，提示未接入，不自动跨越隔离带、翻上高架或放宽距离。
2. **开口允许哪几种走法**：规则至少能区分可从哪些方向驶入、可朝哪些方向驶出，不从整条路是否双向反推。单行与右进右出必须区分。主干路开口条件、道路等级优先和交叉口间距按适用地区的规定核对，不以临时游戏规则替代。

辅路承接沿线进出，匝道处理不同道路或主辅路之间的车辆转换。只有视觉上贴近或交叉，没有合法连接，就不能在寻路图中互通。
