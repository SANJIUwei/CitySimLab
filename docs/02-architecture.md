# 架构笔记

## 项目等级

长期学习型项目。当前阶段只搭环境，不实现玩法。

## 模块边界

- `CitySim.Core`：你写核心规则的地方。这里不引用 Unity。
- `CitySim.Headless`：没有 Unity 时的运行入口。
- `CitySim.UnityMock`：用少量类型模拟 Unity 生命周期，帮助理解 `Init` / `Update` 这类概念。
- `CitySim.Tests`：验证你的规则。
- `docs`：记录你为什么这样写，以及哪里错过。

## 简单原则

- 先写纯 C#，再想 Unity 表现。
- 先写小规则，再写大系统。
- 先能验证，再谈真实感。
- 初期直接调用方法，不急着做复杂框架。

## 暂时不做

- 不做地图系统答案。
- 不做交通算法答案。
- 不做服务器。
- 不做大型框架。
