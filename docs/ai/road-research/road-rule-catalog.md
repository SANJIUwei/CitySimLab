# 道路规则条目库 · 中国大陆参照

核对：2026-11-20。ID 供策划和测试追溯。这里是现实依据摘要；采用哪种地区、车型和场景由策划文档明确，不把现实中的所有例外偷换成统一默认值。

| ID | 层级 | 适用条件与规则摘要 | 来源 |
|---|---|---|---|
| R01 | 全国 / 通行 | 机动车和非机动车右侧通行；当道路设有机动车、非机动车、行人各自空间时按类别分道；无分道另有规则。右侧通行不等于单向。 | 道交法 35–36 条 |
| R02 | 全国 / 通行 | 专用车道限指定车辆；道路可根据实际施加限行或禁行。具体路段的单行、车型限制、时段以该处交通组织为准。 | 道交法 25、37–39 条；GB 5768.2 / .3 |
| R03 | 全国 / 通行 | 标志限速适用；无标志不能只凭道路名称猜车速，应适用实施条例的条件规则并保持安全速度。设计速度不是限速。 | 道交法 42 条；实施条例 45–46 条；GB 55011 3.1.2 |
| R04 | 全国 / 通行 | 在有信号且划有导向车道的路口，按行驶方向驶入相应车道。信号、标志、标线及现场指挥适用各自条件；红灯通常影响通行时机，不必永久移除路线。 | 道交法 25、26、38、44 条；实施条例 51 条 |
| R05 | 全国 / 通行 | 无信号、无交警路口先看标志标线是否规定优先；无控制时进入前停车瞭望并让右方来车，转弯让直行，对向右转让左转，适用条文的完整条件。禁掉头或禁左转标记及若干危险地点不得掉头。 | 实施条例 49、52 条 |
| R06 | 全国 / 工程 | 城市快速路与各等级道路交叉应设置立交；互通匝道出入口应配变速车道等条件。立体相交不代表可以换路，连接取决于是否有实际匝道/连接设施。 | GB 55011 4.0.3、4.0.7 |
| R07 | 全国 / 工程 | 道路出入口、分隔带、缘石开口、交叉口应结合交通组织配置；先区分楼门、地块车行开口、主辅路转换点。 | GB 55011 3.2.2；见专题 |
| R08 | 济南 / 地方 | 快速路主路不设地块出入口；大量人车流地块不宜直连快速路辅路；特定公共设施确需开口时按当地条件右进右出。不能推广到全国所有双向道路。 | 济南规划技术规定 114 条，2026-04-15 实施；见专题 |
