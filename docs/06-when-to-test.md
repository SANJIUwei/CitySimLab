# 什么时候测

AI 写功能和测试。不要写一个测一个。用户只策划和监督。

## 原则

后面统一测。讨论、加字段、改名字、填 TODO 的过程中不插测试。

## 不测

- 每加一个字段或改一个名字
- 只改注释、TODO
- 主题还没写完的半成品
- 编译都还没过的代码（先修编译）

## 要测（攒到一起一次做）

1. **一个主题做完**  
   例如「节点在哪」整段结束：能构造、能赋坐标、能读出来。不是每写一行。
2. **一条规则有明确输入输出**  
   例如两点距离是 5、相同点是 0。
3. **准备提交或推送前**  
   跑 `tools\verify.ps1`（编译 + 已有测试 + Headless）。
4. **用户明确说「测一下」**

## 怎么攒

- 按主题攒：同一段讨论里的改动，等这段说「可以了」再补测试、跑一次。
- 测试仍由 AI 写在 `tests/CitySim.Tests`，用户不写测试。
- Headless 打印也算观察，不代替主题结束时的那一轮测试。
