# 迭代路线

这份路线只规定学习顺序，不提供玩法答案。每一步都应该由你先尝试实现。

## 0. 环境

- 工程可以编译。
- 测试可以运行。
- 命令行入口可以启动。

## 1. 第一个核心对象

- 你决定先表示什么：格子、道路、城市时间，三选一即可。
- 写一个最小类或结构。
- 写一个测试证明它按你的预期工作。

## 2. 第一个规则

- 规则必须足够小。
- 规则必须能用测试验证。
- 规则失败时，要能说清楚输入、输出和原因。

## 3. 第一个运行实验

- 把核心规则接到 `CitySim.Headless`。
- 用命令行观察结果。
- 把观察记录写进 `docs/`.

## 4. 重复迭代

- 每次只加一个机制。
- 每次先预测结果，再运行验证。
- 每次保留一个测试，防止旧规则被改坏。

当前已过：坐标、路网、建筑挂路、出行流水线、通用调度、寻路中心。下一刀见 `docs/design-notes/2026-09-11-current-problems.md`。

## 5. 后期方向

- 可视化。
- 存档。
- 交通。
- 经济。
- 网络同步。

这些以后再碰。现在的任务是学会把一个小规则写对。
