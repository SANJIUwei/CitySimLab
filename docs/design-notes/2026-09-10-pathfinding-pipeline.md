# 寻路流水线（未全部实现）

日期：2026-09-10
状态：设计记录。排队调度以后再写。

## 已定流程（建筑 A → 建筑 B）

1. 建筑挂在 segment 上，位置用缓存的 t，不现场搜段。
2. 入口 Node：只在该段两个端点里挑离入口近的那个（不是扫全图最近 Node）。
3. 全局：Node 之间按 Segment.Cost 做最短路（Dijkstra，不用 BFS，因为 BFS 无视边权）。
4. 路线发给载具后，到第一个 Node 之前、离开最后一个 Node 之后，用局部本能（沿段走到 t / 进门）。
5. Cost 以后可含限速、禁行、排队；现在只是一个 double。

## 以后：求路排队

全局寻路会很热。不要每辆车每帧自己搜。做成请求队列，每帧处理定额条，算完把 Node 序列发给载具。现在仍是同步 `FindPath`。
