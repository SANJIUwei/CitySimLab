# 路网系统 · 给你看的思路图

这不是实现清单，也不是定稿。打开本文件后用 Markdown 预览看图。

```mermaid
mindmap
  root((路网系统))
    三层拆分
      路网图层
        RoadNode 路口或端点
        RoadSegment 连接两个节点
        长直路也可以由多段组成
      建筑接入层
        建筑用世界坐标摆
        入口挂到某条路段
        记下 segment 和 t
      局部接近层
        全局寻路先走到附近道路
        最后一小段用局部逻辑
        不要把每栋建筑塞进永久图
    坐标
      已有 WorldPosition
      已有直线距离
      看见的路不等于寻路用的图
    寻路边界
      全局只在路网上搜
      一次路线通常只处理起点和终点的接入
      现在还不到写 A*
    摆放参考
      天际线：贴路建，结点清楚，看起来假
      狂热运输：自由摆再连路，连接不好看
      这两件事先分开记，还没选
    现在停在哪
      道路架构还没想清楚
      先把关系看明白
      再开始写类
```

## 对照文字

- **路网图层**：稳定的点和段，给全局寻路用。
- **建筑接入层**：入口挂在路段上，存 `segment + t`（`t=0` 是段起点，`t=1` 是段终点）。
- **局部接近层**：路找到了以后，再走入口前最后那一小段。
- **还没拍板**：贴路建设更清晰，自由摆放更自然；逻辑和观感先不要合成一套。
