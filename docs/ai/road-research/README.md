## 后续收录方式

用户发来链接、文件、图片或自己的观察后，登记日期、地区、来源、要点和核对状态。链接记原地址；会过期且适合归档的附件，经核对后在本目录下按主题保留可用副本或稳定引用。可引用的原文、现实规则摘要和游戏取舍分开；新决定注明替代了哪一条。不要因现实资料中存在某种规则便当作游戏需求。继续讨论道路前，先读这里和决策记录。收录资料不等于授权改代码、提交或推送。
