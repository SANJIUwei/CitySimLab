# 不用 Unity 的验证方式

你现在不使用 Unity 验证，所以这个环境提供三种替代方式。

## 1. 编译验证

```powershell
dotnet build
```

编译通过只能说明代码语法和引用没问题，不能说明玩法正确。

## 2. 测试验证

```powershell
dotnet test
```

测试用来回答明确问题。你每写一个小规则，就给它配一个最小测试。

## 3. 观察验证

```powershell
dotnet run --project src\CitySim.Headless
```

命令行入口用于观察你自己的实验结果。它不漂亮，但很适合学习，因为输出越朴素，规则越藏不住。
